# final_project_technologies_for_data_science
A Human Activity Recognition (HAR) project that analyzes accelerometer sensor data to identify and predict different human activities.

The project uses acceleration measurements along the X, Y, and Z axes to extract movement patterns and classify the performed activity.
Machine learning methods used in the project include:
Decision Tree (ID3) – for activity classification based on extracted features.
Naive Bayes – for probabilistic classification of activities.
Linear Regression – for analyzing acceleration trends and identifying changes in movement.
Gaussian Process Regression (GPR) with an RBF kernel – for predicting acceleration behavior over time.
The project demonstrates the complete process of working with sensor data, from acceleration measurements and feature analysis to machine learning-based classification and prediction.
